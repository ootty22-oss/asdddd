# منصة الفيزياء التفاعلية – الثالث المتوسط

منصة تعليمية عربية لمادة الفيزياء (الفصل الأول: الكهربائية الساكنة، الفصل الثاني: المغناطيسية): دروس، مخطط ذهني، مختبر من 14 محاكاة، مسائل، بنك أسئلة واختبارات، بطاقات حفظ، ومساعد يبحث في محتوى الكتاب.

## التشغيل
- **على الإنترنت:** فعّل GitHub Pages من إعدادات المستودع (Settings ← Pages ← Branch: main ← /root).
- **على الجهاز:** افتح `index.html` مباشرة في المتصفح.

## الملفات
- `index.html` الصفحة الرئيسية والتنقل.
- `css/app.css` التصميم.
- `js/` الشيفرة: `app.js` (الموجّه والدروس والتقدم)، `map.js` (المخطط)، `lab.js` (المحاكاة)، `quiz.js` و`problems.js` و`cards.js` و`tutor.js`.
- `data/curriculum.json` كل محتوى المنهج (و`curriculum.js` نسخة منه للتشغيل بدون خادم). لتعديل المحتوى عدّل الملفين معاً.

## ملاحظات
- التقدم يُحفظ في متصفح كل طالب (localStorage) ولا ينتقل بين الأجهزة.
- «اسأل مدرس الفيزياء» خارج claude.ai يعمل مساعداً يبحث في محتوى الكتاب ولا يستعمل الذكاء الاصطناعي، وهذا مكتوب في أعلى صفحته.
